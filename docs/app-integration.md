# App 整合與 adapter 邊界

Cross 使用原生 SwiftUI／Jetpack Compose App。開發版本已驗證虛構心率與合成 ECG 的加密保存、重啟恢復、前景補傳及波形顯示；本文件包不包含 App 原始碼、binary 或可直接嵌入的行動 SDK。

## 目前 App 的量測流程

1. 從合成樣本建立一次量測，固定 event_id、量測時間與完整內容。
2. 保存成功才回報已保存在手機。iOS 使用 AES-GCM／Keychain／檔案保護；Android 使用 AES-GCM／Keystore／AtomicFile，佇列不備份。
3. 重啟恢復同一事件。授權碼只留在記憶體，需重新輸入。
4. 手動補傳、關閉離線演練、返回前景或網路恢復時嘗試同步。
5. 核對 POST 回執，再 GET 讀回確認完整資料，一致後保存同步狀態。
6. 逾時、授權、衝突或資料錯誤各保留事件及對應狀態；不更換 id、不覆蓋損壞檔案。

尚未提供背景持續執行、定時退避、實機配對與正式設備授權。手機測試入口及本機網址只適用開發環境；不要求一般預約使用者下載 App。

## 廠商 adapter 的責任

下一階段的 adapter 將設備封包或 SDK 回呼轉為 Cross 原生事件。它需保存來源時間、設備來源識別、實際取樣率、單位、導程及校正資訊；在正式配對授權完成後，才將事件連結至病人。

Cross 的共用層負責保存、補傳、去重與 API 交換；機型特有的連線、校正與封包解析由 adapter 處理。這個分工讓廠商保留原有設備能力，逐步減少重做 App 與雲端流程的工作。

BLE、Wi-Fi、USB 和廠商 SDK 是待評估的連線方式，本版不宣告已支援其中任何機型或協定。先提供 [最小接入資料](vendor-onboarding.md)，才能估計實作範圍。
